# Прості алгоритми сортування

Програма для практичної: генерація масивів та їх сортування простими алгоритмами.

## Що реалізовано

- Допоміжні методи: генерація масиву заданої довжини з випадкових чисел у заданому діапазоні та виведення масиву у форматі `{[cell - 0,value - 4],[cell - 1,value - 10],...}`

1. Bubble sort (сортування бульбашкою)
2. Insertion sort (сортування вставками)
3. Selection sort (сортування вибором)

Кожен метод сортування приймає несортований масив та вказівник: `True` — сортування за зростанням, `False` — за спаданням.

## Файл

- `task.py` — реалізація на Python

## Запуск

```
python task.py
```

Масив для тестів генерується випадково, тому результати щоразу відрізняються. Кожен алгоритм працює з копією початкового масиву, тому всі три отримують однакові вхідні дані.
